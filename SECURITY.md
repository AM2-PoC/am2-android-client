# Security

Report suspected vulnerabilities through GitHub's **Report a vulnerability** flow: https://github.com/AM2-PoC/am2-android-client/security/advisories/new

Do not include undisclosed vulnerability details in public issues or pull requests. Include the affected app version/API level, impact, reproduction conditions, and a minimal non-destructive proof in the private report.

Never include credentials, tokens, private keys, keystores, passwords, personal or production data, or destructive proof-of-concept payloads in issues, pull requests, logs, or fixtures.
